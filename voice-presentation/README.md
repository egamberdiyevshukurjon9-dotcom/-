# Овозли презентация — флешкага мустақил пакет

Флешкани компьютерга улайсиз, `START.bat` ни босасиз — презентация тўлиқ экранда очилади ва
«кейингиси», «олдингиси», «5 слайд», «қора экран», «чиқиш» каби сўзлар билан бошқарилади.

- **Офлайн**: овозни таниш компьютернинг ўзида (Vosk, ўзбек/рус/инглиз моделлари). Интернет шарт эмас.
- **Ҳеч нарса ўрнатилмайди**: флешка ичида Python, кутубхоналар ва моделлар бор. Администратор ҳуқуқи керак эмас.
- Windows 10/11 (64-бит). PowerPoint бўлса — PowerPoint орқали, бўлмаса LibreOffice/WPS (тугмалар босилади).

## Тайёр пакетни олиш

Пакетни GitHub Actions ўзи йиғади ва Windows'да синайди.

1. GitHub репозиторийси → **Actions** → «Build flash package» → охирги муваффақиятли ишга тушиш.
2. Пастдаги **Artifacts** бўлимидан `VoicePresentation-Flash` ни юкланг (GitHub'га кирган
   бўлишингиз керак; артефакт 30 кун сақланади).
3. Юкланган `.zip` ни очинг: ичида `START.bat` ва `VoiceApp` папкаси бевосита чиқади. Ҳаммасини
   флешканинг илдизига нусхаланг, презентацияни `presentation.pptx` номи билан шу ерга қўйинг.
   Бошқа қадамлар — `flash/README.txt` да (у флешкага ҳам тушади).
4. Очиқ юклаб олиш ҳаволаси керак бўлса: **Actions → Build flash package → Run workflow** да
   «Тайёр пакетни GitHub Release сифатида эълон қилиш»ни белгиланг (репозиторий очиқ бўлса,
   Release ҳамма учун кўринади).

Ўзингиз йиғмоқчи бўлсангиз (интернет керак, ~200 МБ юклайди):

```
python tools/build_flash.py            # dist/VoicePresentation-Flash/ ва .zip
python tools/build_flash.py --no-models   # моделларсиз, тез
```

## Тузилиш

```
app/                    дастур (Python 3.12, ташқи кутубхоналар: vosk, sounddevice, pywin32)
  presentation_voice.py   кириш нуқтаси, режимлар (--test, --selftest, --watch ...)
  commands.py             матндан буйруқни аниқлаш (ўзбек лотин/кирил, рус, инглиз)
  router.py               буйруқни бажариш, автоматик ўтиш, таймер
  engines.py              Vosk (офлайн) ва Google (онлайн) моторлари
  audio.py                микрофон: қайта улаш, жимликни аниқлаш, жумлаларга бўлиш
  backends.py             PowerPoint (COM), тугмалар симуляцияси, синов режими
  winkeys.py              ctypes SendInput (pyautogui ўрнига)
flash/                  флешкага тушадиган шаблонлар: START.bat, TEST.bat, config.json ...
tools/build_flash.py    пакетни йиғиш; tools/ci_smoke.py — Windows'да текшириш
tests/                  юнит-тестлар
```

## Дастурчилар учун

```
python -m unittest discover -s tests          # тестлар (Windows'сиз ҳам ишлайди)
python app/presentation_voice.py --test       # презентациясиз овозни синаш
python app/presentation_voice.py --selftest   # муҳитни текшириш
python app/presentation_voice.py --wav f.wav --expect next   # овоз файли билан Vosk синови
python app/presentation_voice.py --word-check keyingi,oldingi   # сўзлар Vosk моделида борми
```

Асосий қарорлар:

- **Тасодифий ишга тушишдан ҳимоя**: буйруқ сўзидан ташқари жумлада фақат тўлдирувчи сўзлар
  («слайд», «ўтказ», «илтимос», …) бўлиши мумкин. «keyingi misol» оддий гап ҳисобланади.
  Узун гаплар (`max_words`) ва кесилган узун нутқнинг «думи» ҳам ташланади.
- **Vosk грамматикаси**: ҳар бир буйруқ сўзининг ёзилиш вариантлари (лотин, кирил, апостроф)
  моделдан `vosk_model_find_word` билан сўралади, бор бўлганлари грамматикага киради.
  `--selftest --verbose` қайси буйруқ учун қайси сўзлар қолганини кўрсатади.
- **Бир нечта модель** (`vosk_models`): битта овозга улар турли буйруқ қайтарса, рўйхатдаги
  биринчи модель (асосий тил) ютади.
- **Кирил ҳарфли йўл**: Vosk (C++) бундай йўлдан моделни очолмайди; дастур қисқа (8.3) ном ёки
  `ProgramData\VoicePresentation\links` да лотин ёзувли папка-ҳавола (junction) ишлатади.
- **Икки мотор бирга** (`engine: both`): буйруқ овоз айтилган вақт белгиси билан келади,
  шунинг учун Vosk ва Google бир сўзни турли пайтда қайтарса ҳам, слайд бир марта ўтади.
- **Хавфсизлик**: презентация фақат ўқиш режимида ва макросларсиз очилади
  (`AutomationSecurity = msoAutomationSecurityForceDisable`).
- `autorun.inf` ишлатилмайди: Windows 7 дан бошлаб флешкада ишламайди. Ўрнига
  `INSTALL_AUTOSTART.bat` фонда кузатувчи дастурни ўрнатади.

## Текширув ҳолати

Linux'да автоматик тестлар, Windows'да (GitHub Actions) эса пакет тоза машинада йиғилиб:
импортлар, COM, SendInput, Vosk + Windows TTS билан инглизча овоз, `START.bat` занжири ва
кирил ҳарфли папкадан ишга тушириш текширилади. **Ҳақиқий PowerPoint ва ҳақиқий микрофон
CI'да йўқ** — шу сабабли биринчи марта `TEST.bat` билан ўзингизнинг компьютерингизда
синаб кўринг.
