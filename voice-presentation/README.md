# Презентацияни флешка орқали очиш ва овоз билан бошқариш

Флешкадаги презентацияни автоматик очади, тўлиқ экранга чиқаради ва микрофон орқали
«кейингиси», «олдингиси», «5 слайд», «қора экран», «чиқиш» каби буйруқларни бажаради.
Windows 10/11 учун. Ўзбек (лотин ва кирил), рус ва инглиз сўзлари тушунилади.

## 1. Бир марта тайёрлаш

1. Компьютерга [Python](https://www.python.org/downloads/) ўрнатинг («Add python.exe to PATH» катагини белгиланг).
   PyAudio ўрнатилмаса, Python 3.11 ёки 3.12 ишлатинг.
2. Шу папкадаги файлларни флешканинг ичига нусхаланг (`tests/` керак эмас).
3. Презентацияни флешкага **`presentation.pptx`** номи билан қўйинг.
   (Бошқа ном ҳам бўлади: дастур флешкадаги энг янги `.pptx/.ppt/.ppsx/.odp` файлни олади.)

## 2. Ишлатиш

Флешкани уланг → **`START.bat`** ни иккита босинг. Биринчи ишга туширишда кутубхоналар
ўрнатилади (интернет керак). Кейин презентация тўлиқ экранда очилади ва дастур тинглай бошлайди.
Микрофонга «кейингиси» денг.

`Ctrl+C` ёки «чиқиш» — тугатиш.

## 3. Флешка уланганда ўзи очилиши

**`autorun.inf` бу ерда йўқ — у ишламайди.** Windows 7 дан бошлаб флешкалардаги `autorun.inf`
`open=` буйруғини бажармайди (хавфсизлик сабабли), антивируслар эса уни шубҳали деб белгилайди.

Ўрнига, ўз компьютерингизда **`INSTALL_AUTOSTART.bat`** ни бир марта ишга туширинг. У фонда
флешка уланишини кутадиган дастурни Windows билан бирга ёқиладиган қилиб қўяди: флешка
уланса ва ичида презентация бўлса, у ўзи очилади. Ўчириш: `UNINSTALL_AUTOSTART.bat`.
Бегона компьютерда фақат `START.bat` ишлатилади.

Python йўқ компьютерлар учун: Python бор компьютерда `build_exe.bat` ни ишга туширсангиз
`VoicePresentation.exe` ҳосил бўлади; уни флешкага `START.bat` ёнига қўйинг (`START.bat` уни ўзи топади).

## 4. Буйруқлар

| Айтинг | Нима бўлади |
|---|---|
| кейингиси / keyingisi / davomi / next / далее | кейинги слайд |
| олдингиси / oldingisi / orqaga / back / назад | олдинги слайд |
| бошидан / boshidan | биринчи слайд |
| охирги / oxirgi | охирги слайд |
| 5 слайд / beshinchi slayd / slayd 12 | шу рақамли слайдга ўтиш |
| қора экран / qora ekran, оқ экран / oq ekran | экранни қора ёки оқ қилиш |
| экранни оч / ko'rsat | экранни қайтариш |
| тинглама / tinglama → тингла / tingla | микрофонни вақтинча ўчириш ва қайта ёқиш (эркин гапириш учун) |
| бошла / boshla | тўхтаган намойишни қайта бошлаш |
| чиқиш / chiqish / tugat / exit | ёпиш ва чиқиш |
| ёрдам / yordam | буйруқлар рўйхати |

Буйруққа «слайд», «ўтказ», «илтимос» каби сўзларни қўшса бўлади («keyingi slaydga o'tkaz»).
Бошқа сўзлар қўшилса («keyingi misol»), у оддий гап ҳисобланади ва слайд ўтмайди.

## 5. Қўшимча имкониятлар

- **Тўхтовсиз тинглаш**: таниш вақтида айтилган сўз қолиб кетмайди.
- **Нотўғри эшитишга чидамли**: «oldinga» ва «oldingi» чалкашмайди; аниқ бўлмаса ҳеч нима қилинмайди.
- **Оддий нутқдан ҳимоя**: узун гаплар интернетга юборилмайди ва буйруқ бўлмайди; бир буйруқ 1 сония ичида икки марта бажарилмайди.
- **Охирги слайдда шоу ёпилиб қолмайди** («Бу охирги слайд» деб қолади).
- **Хавфсизлик**: презентация фақат ўқиш режимида ва **макросларсиз** очилади.
- **Заҳира режими**: PowerPoint топилмаса (LibreOffice, WPS, `.odp`), F5 ва стрелка тугмалари босилади. Бу режимда презентация ойнаси фаол бўлиши керак.
- **Флешка узилса** — дастур ўзи тугайди (`--watch` режимида яна кутишга қайтади).
- `--attach` — PowerPoint'да аллақачон очиқ презентацияни бошқариш.

## 6. Созламалар (`config.json`)

| Калит | Маъноси |
|---|---|
| `languages` | `["uz-UZ"]`; `["uz-UZ", "ru-RU"]` қилса рус тили ҳам тушунилади (сўровлар 2 баравар кўпаяди) |
| `mic_index` | бир нечта микрофон бўлса: `python presentation_voice.py --list-mics` дан рақам |
| `extra_words` | ўз сўзларингиз, масалан `{"next": ["davay"], "prev": ["ortga qayt"]}` |
| `wake_word` | масалан `"slayd"` — буйруқ шу сўздан бошланса ишлайди (энг ишончли ҳимоя) |
| `max_words` | шундан узун гап буйруқ эмас (стандарт 4) |
| `beep` | буйруқ қабул қилинганда овозли сигнал |
| `log_file` | `"voice_log.txt"` — нима эшитилгани ёзилади |
| `verbose` | буйруқ бўлмаган эшитилган матнни ҳам кўрсатади |

## 7. Муаммолар

- **Ҳеч нима эшитмайди**: Windows → Созламалар → Махфийлик → Микрофон → «ўзбек иловаларига рухсат»ни ёқинг. `--test` билан синаб кўринг.
- **Буйруқни тушунмаяпти**: `python presentation_voice.py --test` ишга туширинг — у презентациясиз ишлайди ва нима эшитилганини кўрсатади. Эшитилган шаклни `extra_words` га қўшинг.
- **«Интернет билан алоқа йўқ»**: таниш Google орқали онлайн ишлайди (бепул, номаълум чекловлар билан). Интернетсиз буйруқлар ишламайди; презентацияни одатдагидек қўлда бошқарса бўлади.
- **Микрофон ёки PyAudio хатоси**: `pip install PyAudio`; Python 3.11/3.12 тавсия этилади.

## 8. Тестлар

```
python -m unittest discover -s tests
```

Буйруқларни аниқлаш, слайд мантиқи, флешкадан файл қидириш ва тинглагич занжири (сохта таниш
билан) текширилади. PowerPoint COM, ҳақиқий микрофон ва `.bat` файллар **Windows'да қўлда
синалиши керак**.
