ОВОЗЛИ ПРЕЗЕНТАЦИЯ — ФЛЕШКА ПАКЕТИ
=====================================

Флешкани компьютерга улайсиз, START.bat ни босасиз — презентация тўлиқ экранда очилади ва
«кейингиси», «олдингиси» каби сўзлар билан слайдлар ўтади. Интернет шарт эмас.

1. ТАЙЁРЛАШ (бир марта)
-----------------------
  ЭНГ ОДДИЙ ЙЎЛ — битта файл: VoicePresentation-Setup.exe ни флешкага нусхаланг ва икки марта босинг.
  У ўз ичидаги ҳамма нарсани (Python, моделлар, дастур) шу флешкага ўзи очади. Кейин START.bat ни босинг.
  (Windows «номаълум нашриётчи» деса: «Қўшимча маълумот» → «Барибир ишга тушириш». Ишламаса —
  қуйидаги қўлда усулдан фойдаланинг.)

  Қўлда: архивни очиб, ИЧИДАГИ ҲАММА НАРСАНИ (VoiceApp папкаси билан) флешканинг илдизига нусхаланг.
  1) 
  2) Презентацияни ҳам флешканинг илдизига «presentation.pptx» номи билан қўйинг.
     (Бошқа ном ҳам бўлади: дастур флешкадаги энг янги .pptx/.ppsx/.ppt/.odp файлни олади.)
  3) Флешкани қаерда ишлатсангиз, шу компьютерда START.bat ни иккита босинг.

  Керак бўлади: Windows 10/11 (64-бит), микрофон, презентацияни очадиган дастур
  (PowerPoint, LibreOffice ёки WPS). Python, интернет ва администратор ҳуқуқи КЕРАК ЭМАС.

2. ИШЛАТИШ
----------
  START.bat  — презентацияни очади ва овозни тинглайди.  Тугатиш: «чиқиш» дейиш ёки Ctrl+C.
  Керакли презентацияни танлаш: ФАЙЛНИ START.bat НИНГ УСТИГА СУДРАНГ (йўлида пробел бўлса ҳам ишлайди).
  Папкада бир нечта презентация бўлса ва «presentation.pptx» йўқ бўлса, энг янгиси олинади.

  Микрофонга аниқ ва равон гапиринг, буйруқ сўзидан кейин бир оз тўхтанг (ярим сония).

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │ кейингиси / keyingisi / далее / next ..... кейинги слайд                    │
  │ олдингиси / oldingisi / назад / back ..... олдинги слайд                    │
  │ бошидан / boshidan ....................... биринчи слайд                    │
  │ охирги / oxirgi .......................... охирги слайд                     │
  │ «5 слайд» / «beshinchi slayd» ............ 5-слайдга ўтиш                   │
  │ «2 слайд олдинга» / «3 slayd orqaga» ..... нисбий ўтиш                      │
  │ қора экран / оқ экран .................... экранни қора / оқ қилиш          │
  │ экранни оч / ko'rsat ..................... экранни қайтариш                 │
  │ автоматик / «avtomatik 20 soniya» ........ ҳар N сонияда ўзи ўтади          │
  │ қўлда / qo'lda ........................... автоматик ўтишни ўчириш          │
  │ ҳолат / vaqt ............................. слайд рақами ва вақт             │
  │ белгила / belgila → белгига қайт ......... слайдни эслаб қолиш ва қайтиш    │
  │ ҳисобот / hisobot ........................ слайд вақтлари, статистика       │
  │ изоҳ / izoh .............................. слайд изоҳини чиқариш            │
  │ мундарижа / mundarija .................... слайдлар рўйхати                 │
  │ тинглама / tinglama → тингла / tingla .... микрофонни вақтинча ўчириш       │
  │ бошла / boshla ........................... намойишни қайта бошлаш           │
  │ чиқиш / chiqish → ҳа / ha ................ ёпиш (тасдиқ билан), «yo'q» — бекор │
  │ ёрдам / yordam ........................... буйруқлар рўйхати                │
  └─────────────────────────────────────────────────────────────────────────────┘

  Буйруққа «слайд», «ўтказ», «илтимос» каби сўзларни қўшса бўлади («keyingi slaydga o'tkaz»).
  Бошқа сўзлар қўшилса («keyingi misol») — бу оддий гап, слайд ўтмайди. Шунинг учун нутқ
  пайтида тасодифан слайд ўтиб кетмайди.

3. ҚЎШИМЧА ИМКОНИЯТЛАР
-----------------------
  PULT.bat ......... ТЕЛЕФОН ПУЛТИ. Телефон ва компьютер бир Wi-Fi'да бўлсин. Қора ойнада чиққан
                     ҳаволани телефон браузерида очинг: катта «Кейинги ▶» тугмаси, слайд рақами, вақт.
                     Ҳавола ичида сессия калити бор — уни бошқаларга берманг. Windows ёнғинга қарши
                     девор сўраса, «Хусусий тармоқлар»га рухсат беринг. Алоқа шифрланмайди (HTTP), шунинг
                     учун фақат ишончли Wi-Fi'да ишлатинг.
                     REST API (IFTTT, вебхук, скрипт учун):
                       GET|POST  http://IP:8765/api/command/next?t=КАЛИТ
                       GET|POST  http://IP:8765/api/command/goto?t=КАЛИТ&n=5
                       GET       http://IP:8765/api/status?t=КАЛИТ        (ҳолат, JSON)
                     Буйруқлар: next prev first last black white unblank goto jump mark to_mark
                     auto_on auto_off pause_listen resume_listen start status notes outline report exit.
  KALIBROVKA.bat ... ТАНИШ АНИҚЛИГИНИ ЎЛЧАШ (≈3 дақиқа). Дастур 10 та буйруқни 3 мартадан айттиради,
                     Vosk ва Google қанчалик тўғри эшитганини фоизда кўрсатади. Бир сўзни такрор
                     нотўғри эшитса («keyingisi» ўрнига ҳар сафар «kegingi»), уни сизнинг шахсий алиасингиз
                     сифатида сақлашни таклиф қилади (VoiceApp\learned.json) — кейин у ишлайди.
  HISOBOT.bat ...... Ҳар намойишдан кейин VoiceApp\reports папкасига ҳисобот ёзилади (JSON, CSV, HTML):
                     ҳар слайдга қанча вақт кетгани, буйруқлар, нечта жумла эшитилиб нечтаси буйруқ бўлгани.
                     Машқ қилиш ва вақтни режалаштириш учун қулай.
  Push-to-talk ..... config.json да "push_to_talk": "f9" (ёки "ctrl") қилинг: буйруқ фақат шу тугмани
                     босиб турганда қабул қилинади. Нутқ пайтида тасодифий ўтиб кетишдан энг ишончли ҳимоя.
  Чиқиш тасдиғи .... «chiqish» дегандан кейин дастур сўрайди: «ha» денг (ёки яна «chiqish»). Овоз
                     янглиш эшитилса ҳам намойиш ёпилиб қолмайди. Ўчириш: "confirm_exit": false.

4. ИШЛАМАСА
-----------
  TEST.bat        — компьютерни ва микрофонни текширади, нима етишмаслигини ёзади.
  TEST_VOICE.bat  — презентациясиз: буйруқларни айтинг, дастур нима эшитганини кўрсатади.

  • «Ҳеч нарса эшитмайди»: Windows → Созламалар → Махфийлик → Микрофон → «Иловаларга микрофондан
    фойдаланишга рухсат бериш»ни ёқинг. Бир нечта микрофон бўлса, VoiceApp\config.json да
    "mic" ни ёзинг (рўйхат: START.bat --list-mics).
  • «Буйруқни тушунмаяпти»: TEST_VOICE.bat да нима эшитилганини кўринг. Ўзбекча сўзлар яхши
    танилмаса, config.json да "engine": "both" қилинг (Google ҳам ишлайди, интернет керак).
  • «Windows компьютерингизни ҳимоя қилди» ойнаси: «Қўшимча маълумот» → «Барибир ишга тушириш».
    Архивни очишдан олдин: файл устида ўнг тугма → Хусусиятлар → «Блокдан чиқариш».
  • Презентация PowerPoint'да очилмаса, дастур F5 ва стрелка тугмаларини босиш режимига ўтади
    (презентация ойнаси фаол бўлиши керак).

5. ФЛЕШКА УЛАНГАНДА ЎЗИ ОЧИЛИШИ
-------------------------------
  Windows 7 дан бошлаб флешкадаги autorun.inf ишламайди (хавфсизлик), шу сабабли у йўқ.
  Ўз компьютерингизда INSTALL_AUTOSTART.bat ни бир марта ишга туширинг — дастур фонда
  туради ва флешка уланиши билан презентацияни ўзи очади. Ўчириш: UNINSTALL_AUTOSTART.bat.

6. СОЗЛАМАЛАР (VoiceApp\config.json)
------------------------------------
  engine ............ "auto" (офлайн Vosk, йўқса Google) | "vosk" | "google" | "both" (иккаласи)
  vosk_models ....... ["uz","ru","en"] — қайси тилларда тинглаш. Биринчиси — асосий тил:
                      у фақат буйруқ сўзларини қидиради (тез ва аниқ), қолганлари эркин
                      таниш режимида ишлайди (бегона тилдаги гап тасодифан буйруқ бўлмаслиги учун).
                      Фақат ўзбекча керак бўлса: ["uz"] (бироз тезроқ ишлайди).
  vosk_grammar ...... "primary" (стандарт) | true (ҳамма тилларда) | false (ҳеч қайсисида)
  mic ............... микрофон рақами ёки номи (null — стандарт)
  max_words ......... шундан узун гап буйруқ эмас (4)
  wake_word ......... масалан "slayd": буйруқ шу сўздан бошланса ишлайди (энг ишончли ҳимоя)
  extra_words ....... ўз сўзларингиз: {"next": ["davay"], "prev": ["ortga qayt"]}
  talk_minutes ...... чиқиш вақти (дақиқа); тугашига warn_minutes қолганда сигнал беради
  auto_default_seconds ... «avtomatik» деганда ҳар неча сонияда ўтсин
  confirm_exit ...... true: «chiqish» дан кейин тасдиқ сўралади
  push_to_talk ...... "f9" / "ctrl" / "space" ...: буйруқ фақат шу тугма босилганда ("" — ўчирилган)
  report ............ true: намойиш охирида ҳисобот ёзилади (report_dir — қаерга)
  remote ............ true: PULT.bat'сиз ҳам телефон пультини ёқади (remote_port, remote_token, remote_host)
  beep .............. ҳар буйруқда сигнал
  Файлни Блокнотда очиб ўзгартиринг, сақланг, дастурни қайта ишга туширинг.

7. ЧЕКЛОВЛАР
------------
  • Фақат Windows 10/11 64-бит. Ўзбекча овозни таниш сифати микрофонга ва шовқинга боғлиқ.
  • Папка номида кирил ҳарфлар бўлса (масалан, фойдаланувчи номи «Иван»), модель ҳавола орқали
    уланади: C:\\ProgramData\\VoicePresentation\\links (кичик папка-ҳавола; керак бўлмаса ўчириб юборинг).
  • Бегона компьютерда PowerPoint бўлмаса ва LibreOffice/WPS ҳам бўлмаса, презентацияни очиб бўлмайди.
  • Антивирус флешкадаги .bat файллар ва Python'ни қўшимча текшириши мумкин — бу нормал ҳол.
